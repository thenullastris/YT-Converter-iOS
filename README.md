# YT Converter for iOS

A clean YouTube video & audio downloader for iOS. Sideload via AltStore.

## Features
- Download YouTube videos as MP3 or MP4
- Quality selector: Best / 720p / 480p / 360p
- Native iOS share sheet — save to Files, iCloud, AirDrop
- Recent downloads history
- Dark theme UI

## Requirements
- iOS 16+
- Sideloaded via AltStore or other sideload method

## Build
Provide your own `development.yml` GitHub Actions workflow to build the `.ipa`.
